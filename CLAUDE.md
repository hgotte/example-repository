## Development Environment

This is a simple Python repository with a single Python script (`phyton2.py`) and a Python virtual environment (`example_venv`).

### Python Environment
- Python version: 3.13.5
- Virtual environment located at: `example_venv/`
- To activate the virtual environment: `source example_venv/bin/activate`
- NumPy is the primary dependency used in the codebase

### Development Commands
- **Activate virtual environment**: `source example_venv/bin/activate`
- **Run Python script**: `python phyton2.py`
- **Install dependencies**: `pip install numpy` (if needed)

## Code Structure

The repository contains:
- `phyton2.py`: Main Python script that demonstrates basic NumPy array creation
- `example_venv/`: Python virtual environment with NumPy installed

This is a minimal Python project focused on NumPy array operations. The main script creates a simple NumPy array with integers 1-5.
